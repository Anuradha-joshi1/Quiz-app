# quiz app

A simple and interactive Quiz Application  built using  HTML CSS and TypeScript.  
The app allows users to answer multiple-choice questions, skip questions with confirmation, and view their final score at the end.  



##  Features

-  Questions loaded from a JSON file
-  Multiple-choice questions
-  Option selection with visual highlight
-  Skip question confirmation popup
-  Quiz progress saved using `localStorage`
-  Resume quiz after page refresh
-  Final score and performance message



## Technologies Used

- HTML – Structure
- CSS– Styling
- TypeScript– Logic
- LocalStorage – Persist quiz progress
